SignalTrace Shorts Linker: Privacy Policy

Last updated: October 9, 2026

SignalTrace Shorts Linker is a private tool used only by the owner of the YouTube channel SignalTrace: Finance Explained. It adds a link to the matching X thread (@SignalTraceLab) at the end of the description of the channel's own Shorts. It is not offered to other users.

YouTube API Services

This tool uses YouTube API Services. Using it means agreeing to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What it accesses

Only after the channel owner grants permission, it reads the channel's ID and title, the list of recent uploads (video IDs and titles), and the title, description, category, tags and language settings of a matched video. The only change it makes is appending one link line to that video's description.

What it stores

Everything stays on the channel owner's own computer: the authorization token, the channel ID and title, and a local log of which video was linked to which X thread. Nothing is sent anywhere except to Google's YouTube API.

Sharing

No data is sold, shared or transferred to anyone. There are no ads, analytics or cookies.

Removing access

Access can be revoked at any time in the Google account's third-party connections page. Deleting the local token file also stops the tool.

Contact

Through the YouTube channel or @SignalTraceLab on X.
